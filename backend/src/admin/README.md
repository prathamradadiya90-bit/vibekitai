# VibeKit AI - Admin Console Setup & Security Guide

The VibeKit AI Admin Console is an ultra-lightweight, zero-external-dependency SPA served directly from Cloudflare Workers edge nodes (`/admin`).

## 1. Security Architecture

- **Primary Gate:** Cloudflare Access protecting `/admin/*` and `/v1/admin/*`.
- **JWT Verification:** Authenticates the `Cf-Access-Jwt-Assertion` header generated by Cloudflare Access.
- **Role-Based Access Control (RBAC):**
  - `admin`: Full administrative control (credit grants/revocations, bans, remote config updates, rollback, data purging).
  - `viewer`: Read-only access to KPIs, dashboards, installations, feedback, and audit logs. All mutating operations return HTTP `403 Forbidden`.
- **Zero Prompt Retention Guarantee:**
  - The admin panel never displays or queries user input messages or generated text.
  - Only anonymized installation IDs, timestamps, status codes, and aggregate counts are accessed.
- **Security Headers & Flags:**
  - `X-Robots-Tag: noindex, nofollow`
  - Strict Content-Security-Policy (CSP)
  - CSRF header verification (`X-Admin-Action: 1`) on all mutating endpoints.

## 2. Setting Up Cloudflare Access

1. Log into your **Cloudflare Zero Trust** dashboard (`one.dash.cloudflare.com`).
2. Navigate to **Access** > **Applications** > **Add an application**.
3. Select **Self-hosted**.
4. Configure Application Details:
   - **Application name:** `VibeKit AI Admin`
   - **Session Duration:** `24 hours`
   - **Application domain:** `api.vibekit.ai` (Path: `/admin*` and `/v1/admin*`)
5. Configure Access Policies:
   - **Policy Name:** `Core Admin Team`
   - **Action:** `Allow`
   - **Include Rule:** Emails ending in `@vibekit.ai` or specific developer emails.
6. Copy the **Application Audience (AUD) Tag** from the overview page.

## 3. Worker Secrets Configuration

Store your admin credentials and allowed users using `wrangler secret put`:

```bash
# Set Cloudflare Access Audience Tag
npx wrangler secret put CF_ACCESS_AUD

# Set Cloudflare Zero Trust Team Name
npx wrangler secret put CF_ACCESS_TEAM_NAME

# Set Admin Session Secret (for fallback / CLI access)
npx wrangler secret put ADMIN_SECRET

# Set Admin Role Mapping (JSON format)
npx wrangler secret put ADMIN_USERS_JSON
# Example value:
# {"lead@vibekit.ai": "admin", "analyst@vibekit.ai": "viewer"}
```

## 4. Nightly Cron Trigger

The admin panel computes expensive stats (DAU, WAU, MAU, latency percentiles, revenue estimates) via a Cloudflare Workers Cron Trigger:

- **Schedule:** `0 1 * * *` (1:00 AM UTC daily)
- **Handler:** `handleScheduledTask` in `src/cron/nightly_stats.ts`
- **Manual Trigger:** Available via the Admin Console UI button or `POST /v1/admin/aggregate-daily`.
